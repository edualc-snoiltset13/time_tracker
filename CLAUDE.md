# CLAUDE.md

Guidance for AI assistants (and humans) working in the **time_tracker** repository.

## What this is

A cross-platform **Flutter** time-tracking and invoicing app (for freelancers / consultants /
small teams). It runs on all six Flutter targets: **android, ios, linux, macos, windows, web**.

**Features:** clients & projects (with hourly rates and optional monthly time limits),
live **and** manual time tracking, a priority-based to-do list, expense tracking (including
mileage = distance × cost-per-unit), PDF invoice generation, reports (bar charts), company
settings (logo/letterhead), and idle detection that prompts when the user goes inactive.

## Tech stack

- **Dart** SDK `^3.8.1`; Flutter stable channel. App version `1.0.0+1`, `publish_to: none`.
- **State management:** [`provider`](https://pub.dev/packages/provider) — *not* Riverpod or Bloc.
- **Persistence:** [`drift`](https://pub.dev/packages/drift) (type-safe SQLite ORM) +
  `sqlite3_flutter_libs`. DB file `app_tracker.sqlite` lives in the app support directory
  (`path_provider`).
- **PDF/printing:** `pdf`, `printing`, `open_file`. **Charts:** `fl_chart`.
  **Formatting:** `intl`. **Images/files:** `image_picker`, `file_picker`.
- **Codegen (dev):** `drift_dev` + `build_runner`. **Lints:** `flutter_lints`.

## Database schema (`lib/database/database.dart`)

`AppDatabase` is a `@DriftDatabase` with **`schemaVersion = 3`** and a `MigrationStrategy`
(e.g. adding `TimeEntries.isLogged`). Seven tables:

| Table | Notes |
|-------|-------|
| `Clients` | name, optional email/address, `currency` (default `'USD'`) |
| `Projects` | FK `clientId` (cascade), `hourlyRate`, nullable `monthlyTimeLimit`, `status` |
| `TimeEntries` | FK `projectId` (cascade), `startTime`, nullable `endTime`, flags `isBillable`/`isBilled`/`isLogged` |
| `Expenses` | nullable FKs `projectId`/`clientId`, `amount`, nullable `distance`/`costPerUnit` (mileage) |
| `Invoices` | FK `clientId` (cascade), `invoiceIdString`, dates, `totalAmount`, `lineItemsJson` |
| `Todos` | FK `projectId` (cascade), `priority`, `deadline`, `startTime`, nullable `estimatedHours` |
| `CompanySettings` | singleton row: company name/address, logo path, `showLetterhead` |

UI reads data reactively with `StreamBuilder` + Drift `.watch()`; one-off loads use
`FutureBuilder`. Forms are `StatefulWidget`s.

## Common commands

```bash
flutter pub get                 # Install dependencies
dart run build_runner build     # Regenerate database.g.dart (run after ANY schema change)
flutter run                     # Run on a connected device/emulator
flutter test                    # Run tests (only a placeholder exists today)
flutter analyze                 # Static analysis (flutter_lints)
flutter build <apk|ios|linux|macos|windows|web>
```

**Important:** after editing `lib/database/database.dart` (or any Drift table/query), you
**must** re-run `dart run build_runner build` so `database.g.dart` stays in sync. Never edit
the generated file by hand.

## Conventions

- `PascalCase` types, `camelCase` members, `_leadingUnderscore` for privates.
- Screens grouped by feature under `lib/screens/<feature>/`; one list screen + edit screen each.
- **Async safety:** check `mounted` after awaits; capture `ScaffoldMessenger`/`Navigator`
  before async gaps; `dispose()` controllers in `StatefulWidget`s.
- Swipe-to-delete via `Dismissible`; form validation via `_formKey.currentState!.validate()`.
- Lints are stock `flutter_lints` (no custom overrides) — keep `flutter analyze` clean.

## Gotchas

- **Tests are effectively absent** — `test/widget_test.dart` is a placeholder. Add real tests
  before claiming behavior is verified.
- **No CI** — `.github/` only contains `FUNDING.yml`; there are no workflows.
- **`add_two_numbers.py`** at the repo root is unrelated to the Flutter app (orphaned).
